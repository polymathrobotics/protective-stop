# External Contributions

An external pull request that arrives without a Change Request is labelled `needs-change-request`, and review does not begin yet. This is maintainer work, not a requirement placed on the contributor.

A maintainer opens the Change Request on the contributor's behalf, classifies the change, and completes the Impact Analysis using the project's safety context. Once the Change Request exists and is authorized, the maintainer removes `needs-change-request` and normal checks and review apply.

Contributors should describe the intended change and provide tests where possible. They are not expected to author the project's safety Impact Analysis.
